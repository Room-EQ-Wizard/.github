## What Is Room EQ Wizard

Room EQ Wizard (REW) is a measurement suite for people who already have a room, speakers, and a calibrated mic. You generate a sweep, capture Room EQ Wizard room measurement at the chair you actually use, then read the overlay. Room EQ Wizard RTA is the live view. Room EQ Wizard EQ filters are the practical output: a set of cuts and boosts aimed at a DSP you administer. Room EQ Wizard acoustic analysis is the wider set of plots - spectrograms, waterfalls, distortion, RT60.

This is not a music player and not a mastering suite. Home-theater owners, small-studio builders, and installers measuring a room they were hired to treat all use the same idea: put data under the EQ. A pretty curve on a phone app is not the same as a sweep with a known mic calibration file you own.

REW will not fix a room you refuse to treat. Measure, add panels or placement you already planned, measure again. Keep traces labeled by seat and date. Work only in spaces you control or were asked to measure.

## Starting with Room EQ Wizard

Prerequisites: A PC you administer, an interface, a measurement microphone with a calibration file you keep, and a room you control.

1. **Prepare:** Place the mic at ear height in the main seat, load the calibration file, and set playback to the speakers under test.
2. **Configure:** Set output and input levels so Room EQ Wizard room measurement sweep is loud enough without clipping.
3. **Test:** Run one sweep and confirm Room EQ Wizard RTA or the resulting curve looks like a real room, not a disconnected cable.
4. **Refine:** Measure extra seats, then generate Room EQ Wizard EQ filters against a house curve you actually want.
5. **Apply:** Load those filters into the DSP or equalizer you already run, and sweep again.
6. **Maintain:** Save traces with dates. After furniture or treatment changes, measure the space you control once more.
